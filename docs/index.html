Key Principle

The Purdue Model defines zones and conduits for industrial networks. Each level has distinct security requirements. Traffic should never cross more than one level without passing through a security control (firewall, DMZ, data diode).

About OpenICS-Atlas

OpenICS-Atlas is an open-source tool for defenders to visualize internet-exposed ICS/OT services, understand the Purdue Model architecture, and generate practical hardening checklists and firewall policies.

Ethics & Safety

OpenICS-Atlas is strictly for defensive education. The Shodan integration (when enabled) exposes only aggregated statistics — no individual host IPs, banners, or identifying data are ever displayed.

⚠️ Do not use this tool to target, scan, or exploit any device. All demo data is synthetic. Real Shodan integration requires your own API key and returns aggregated counts only.
